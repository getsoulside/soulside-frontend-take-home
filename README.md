## Getting your own copy

Click **"Use this template" → "Create a new repository"** at the top of this page, and **set the
visibility to Private**. Then add **`uttamsdarji`** as a collaborator (Settings →
Collaborators) so we can see it.

That's it — commit your work into that repo and send us the link when you're done.

A few notes on the mechanics, since they trip people up:

- **You can make it private even though this template is public.** The visibility dropdown in
  the "Create a new repository" dialog is yours to set; it doesn't inherit from here.
- **Private repos allow unlimited collaborators on free GitHub accounts**, so you don't need a
  paid plan to add us.
- **Please don't fork.** A fork of a public repo is always public, and it stays permanently
  listed on this repository's Forks tab — which would make your work visible to every other
  candidate. Downloading the ZIP and pushing it to a private repo of your own works fine too, if
  you'd rather.

We ask for private because we reuse this exercise, and public submissions spoil it for the
people who come after you. If you'd like to make it public afterwards for your portfolio, just
tell us once you've heard back either way — we're glad for you to.
